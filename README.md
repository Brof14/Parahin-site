# Personal Website

A static personal website published from this repository. It contains the landing page, a separate life-story page, image assets, and custom-domain configuration.

## Contents

- `index.html` — landing page
- `lifestory.html` — life-story page
- `CNAME` — custom-domain configuration for GitHub Pages
- Image assets used by the pages

## Development

The site is authored as static HTML and does not define a package-manager build step. Edit the relevant HTML and assets, then review the pages in a browser before publishing.

GitHub Pages and DNS settings control the live site. Keep the `CNAME` file aligned with the configured domain.
